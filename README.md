# CONCERT TICKETS:  Interactive Venue Ticketing System
WM1 Student Project: A front-end ticket-selection website for a concert venue, built and designed using HTML, CSS and JavaScript.

## Venue
A rectangular concert arena with a stage, catwalk. and six seated zones at four price categories.

     zone       | category | price_dollars
----------------+----------+---------------
Gold Circle L/R | A        |           180
Floor A         | B        |           120
Left/Right Tier | C        |            85
Floor B         | D        |            55

## Structure
- `index.html` - the single page
- `css/styles.css` - all styling
- `js/venue-data.js` - venue data model and seat generation
- `js/venue-render.js` - rendering seats from the data
- `js/map-controls.js` - zoom and pan controls
- `js/cart.js` - cart state
- `js/main.js` - manages everything together
